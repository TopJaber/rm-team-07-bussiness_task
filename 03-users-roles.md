# 3. Пользователи и роли

## Цели ролей

| Роль | Главная цель в системе | Ключевые действия |
|---|---|---|
| Руководитель | Ставить задачи с одним ответственным и видеть просрочки | Создать, изменить, закрыть задачу; назначить исполнителя; изменить срок; комментировать |
| Исполнитель | Понимать свои задачи и сроки и показывать ход работы | Просматривать свои задачи; изменять разрешённый статус; комментировать; добавлять вложения |
| Клиент-наблюдатель | Видеть состояние своего проекта без запросов менеджеру | Просматривать задачи и публичные статусы своего проекта; оставлять публичные комментарии |

## Матрица роль × действие

| Действие | Руководитель | Исполнитель | Клиент-наблюдатель |
|---|:---:|:---:|:---:|
| Создать задачу | Да | Нет | Нет |
| Изменить задачу | Да | Только статус назначенной задачи | Нет |
| Закрыть задачу | Только если является автором | Только если является автором | Нет |
| Оставить внутренний комментарий | Да | Да | Нет |
| Оставить публичный комментарий | Да | Да | Да |
| Просмотреть проект | Все доступные проекты | Проекты со своими задачами | Только свой проект |
