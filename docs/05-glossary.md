ГЛОССАРИЙ
- **Задача:** - конкретное поручение сотруднику, которое создаёт поставщик
- **Проект:** - группа задач, объединенных одним клиентом
- **Статус** - Этап жизненного цикла задачи, виды: новая, в работе, на проверке, выполнена
- **Просрочка:** - ситуация, когда задача не выполнена, а срок дедлайна закончился
- **Поставщик:** - сотрудник, создавший задачу
- **Наблюдатель:** - видит только статус своего проекта, без права на редактирование
