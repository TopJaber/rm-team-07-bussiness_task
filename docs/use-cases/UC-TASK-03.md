# UC-TASK-03 Закрыть задачу

| Основное действующее лицо | Другие действующие лица | Предусловия |
|---|---|---|
| Руководитель проекта | Клиент-студии, исполнитель проекта | Задача существует и ещё не закрыта. Руководитель проекта является автором задачи. |

## Основной сценарий

1. Руководитель проекта открывает задачу.
2. Руководитель выбирает действие «Закрыть задачу».
3. Система проверяет право пользователя на закрытие задачи.
4. Система фиксирует дату закрытия.
5. Система ставит статус закрытия
6. Система отображает задачу всем пользователям как закрытую.

## Альтернативные сценарии

### A1 Финальный комментарий

1. Перед закрытием руководитель проекта добавляет комментарий.
2. Руководитель закрывает задачу.

### A2 Отмена закрытия

1. Автор отменяет действие закрытия.
2. Система оставляет задачу открытой.

## Исключительный сценарий

1. Исполнитель проекта пытается закрыть задачу.
2. Система отклоняет действие.

## Постусловия

- Успех: задача закрыта и сохранена в системе.
- Неуспех: задача не закрыта.
