# UC-TASK-04 Оставить комментарий к задаче

| Основное действующее лицо | Другие действующие лица | Предусловия |
|---|---|---|
| Исполнитель | Клиент-студии, руководитель проекта | Задача существует. Исполнитель имеет доступ к задаче. |

## Основной сценарий

1. Исполнитель открывает задачу.
2. Исполнитель заполняет форму комментария.
3. Исполнитель выбирает зону видимости комментария.
4. Система сохраняет комментарий.
5. Система проводит рассылку уведомлений.
6. Система показывает комментарий в выбранной зоне видимости.

## Альтернативные сценарии

### A1 Комментарий руководителя

 Руководитель проекта добавляет комментарий за исполнителя.

### A2 Ограниченная видимость

1. Комментарий создаётся с ограниченной зоной видимости.
2. Комментарий доступен только его автору и руководителю проекта.

## Исключительный сценарий

1. Исполнитель не имеет доступа к задаче.
2. Система не позволяет оставить комментарий.

## Постусловия

- Успех: комментарий создан с выбранной зоной видимости.
- Неуспех: комментарий не сохранён, рассылка уведомлений не проведена.
