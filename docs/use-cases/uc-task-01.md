# UC-TASK-01 Создать задачу

| Основное действующее лицо | Другие действующие лица | Предусловия |
|---|---|---|
| Руководитель проекта | Исполнитель проекта | Руководитель и исполнитель добавлены в систему. Проект создан. |

## Основной сценарий

1. Руководитель проекта открывает необходимый проект.
2. Руководитель выбирает функцию создания задачи.
3. Руководитель заполняет форму создания задачи.
4. Руководитель назначает исполнителя.
5. Руководитель нажимает кнопку "создать".
6. Система проверяет форму на валидность.
7. Система отображает задачу.

## Альтернативный сценарий

 Руководитель добавляет в систему описание или вложения.
 
 При недоступном почтовом сервисе задача создается, но система сохраняет ее в память локально.

## Исключительный сценарий

1. Исполнитель не указан.
2. Система не позволяет сохранить новую задачу.

## Постусловия

- Успех: задача создана и назначена исполнителю.
- Неуспех: задача не создана, введённые данные остаются в форме.
