# UC-TASK-02 Изменение статуса задачи

| Основное действующее лицо | Другие действующие лица | Предусловия |
|---|---|---|
| Исполнитель проекта | Руководитель проекта, клиент-студии | Задача создана, не закрыта и назначена исполнителю. |

## Основной сценарий

1. Исполнитель открывает нужную задачу.
2. Исполнитель нажимает кнопку изменения статуса.
3. Система проверяет права доступа исполнителя. 
4. Исполнитель выбирает новый статус.
5. Система изменяет статус задачи.
6. Новый статус отображается руководителю проекта и клиенту-студии.

## Альтернативный сценарий

1. Исполнитель выбирает статус, который уже установлен у задачи.
2. Система сообщает, что этот статус уже установлен, и не изменяет задачу.

## Исключительный сценарий

1. Исполнитель пытается изменить статус чужой задачи.
2. Система запрещает действие.

## Постусловия

- Успех: новый статус принят, руководитель проекта и клиент-студии получают уведомление.
- Неуспех: статус задачи остаётся прежним.
