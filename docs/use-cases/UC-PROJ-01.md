# UC-PROJ-01 Просмотреть статус своего проекта

| Основное действующее лицо | Другие действующие лица | Предусловия |
|---|---|---|
| Клиент-студии | Руководитель проекта | Клиент авторизован и имеет доступ к проекту. |

## Основной сценарий

1. Клиент открывает список проектов, к которым у него есть доступ.
2. Клиент выбирает нужный проект.
3. Система открывает доску выбранного проекта.
4. Система показывает задачи проекта и их статусы.
5. Клиент просматривает доступные комментарии и вложения к задачам.
6. Система не показывает клиенту внутренние комментарии команды.

## Альтернативные сценарии

### A1 В проекте нет задач

1. В выбранном проекте нет задач.
2. Система показывает сообщение «В проекте пока нет задач».

### A2 Переход к другому проекту

1. Клиент фильтрует задачи по статусу.
2. Система показывает подходящие задачи.

## Исключительные сценарии

### E1 Попытка открыть чужой проект

1. Клиент переходит по прямой ссылке в чужой проект.
2. Система запрещает доступ.

### E2 Данные недоступны

1. Данные проекта временно недоступны.
2. Система выводит сообщение об ошибке.

## Постусловия

- Успех: клиент видит разрешённые данные своего проекта, но не видит внутренние комментарии команды.
- Неуспех: данные чужого или недоступного проекта не показаны.
