# 3. Пользователи и роли

## Пользователи

 Директор студии         
 Руководитель проекта    
 Исполнители проекта           
 Клиент-студии       

 ## Роли
 Директор студии - контролирует состояние всех проектов и количество просроченных задач
 
 Руководитель проекта - назначает задачи и исполнителей, контроллирует сроки выполнения
 
 Исполнитель - Просматривает свои задачи и сообщает о ходе работы
 
 Клиент-студии - просматривает задачи и оставляет комментарии
